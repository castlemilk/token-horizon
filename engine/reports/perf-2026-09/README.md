# perf-2026-09: th-engine performance program reports

These files are the primary sources of the 2026-09-25..28 th-engine performance program (phases B–E plus the bench-quiet protocol session), which took th-engine from 0.56× to 1.20× Splash 1.0 decode on Qwen3.8-27B-4bit on an M5 Max (`PHASEB-REPORT.md` §1.1, `phaseE/PHASEE-REPORT.md` §0); what they add up to for the *next* model is written down in two operational documents: [`engine/docs/MODEL-OPTIMISATION-PLAYBOOK.md`](../../docs/MODEL-OPTIMISATION-PLAYBOOK.md), the runbook for a new model optimisation job (correctness gates, floors and baseline, the quiet measurement protocol, lever triage, lanes with per-branch adversarial review, integration, the final same-session A/B, a reporting template and the time and cost these phases actually took), and [`engine/docs/GENERALISATION-PLAN.md`](../../docs/GENERALISATION-PLAN.md), what to change in the engine so a Qwen4-class hybrid, a MoE, a native-MTP model, a non-Qwen family or a new quant format is cheap to onboard (model descriptor, route plan, per-(model, GPU) tune tables, drafter/MTP adapter, phased roadmap, perf CI). Both cite these reports by file and section for every number, and the fuller inventories they condense are in `engine/docs/analysis/`.
