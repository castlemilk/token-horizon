Apple silicon · macOS 14 or later

Browse macOS installers

Release notesSHA-256 checksumsAll releases
  1. Open the disk image

    Drag Token Horizon into Applications.

  2. Launch Token Horizon

    Open it from Applications. Your usage lives at the notch and in the dashboard.

Install with Homebrew or Terminal
Homebrew
brew tap castlemilk/tap
brew install --cask token-horizon
curl -fsSL https://raw.githubusercontent.com/castlemilk/token-horizon/main/install.sh | bash

The one-line installer also enables crash recovery and sets up the th shell helper. Inspect the installer.

Token Horizon for Windows

Windows 10 or 11 · Intel / AMD 64-bit

Browse Windows installers

Release notesSHA-256 checksumsAll releases
  1. Run the installer

    Open the downloaded .exe and choose where to install. It installs for your Windows account.

  2. Open Token Horizon

    Launch it from the Start menu or desktop shortcut.

  3. Set up tracking

    Choose which tools the app can read or meter in the tracking setup guide. Keep the app open while tracking.

Windows installation help

This installer is currently unsigned, so Windows may show a security prompt. Review the release and checksum before deciding to open it. Windows ARM64 is not a native build target.

To update, close Token Horizon and run the newer installer. You can uninstall it from Windows Settings → Apps.

Token Horizon for Linux

64-bit desktop · x64 or ARM64

Debian / Ubuntu: use the .deb package. Other distributions: use the AppImage for your architecture.

Browse Linux installers

Release notesSHA-256 checksumsAll releases
  1. Install or open your package
    Install the downloaded .deb with your package manager, or allow the AppImage to run as a program in file properties.
  2. Open Token Horizon

    Use your application menu for .deb installs, or open the AppImage.

  3. Set up tracking

    Choose which tools the app can read or meter in the tracking setup guide. Keep the app open while tracking.

Linux installation help

Check your architecture with uname -m: x86_64 means x64; aarch64 means ARM64. A graphical desktop is required.

AppImage needs FUSE 2. On Ubuntu 24.04, install libfuse2t64. If your system restricts Chromium’s sandbox, use the .deb package on Debian or Ubuntu.

To update, close the app and install the newer .deb or replace your AppImage.
