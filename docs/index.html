GET GOING

macOS on Apple silicon. No account, no setup wizard — install, glance, verify.

① Install

curl -fsSL https://raw.githubusercontent.com/castlemilk/token-horizon/main/install.sh | bash

One line, no prompts, no sudo. Latest release lands in /Applications, crash auto-recovery switches on, and the th shell command is wired up.

② Glance

Your notch (or menu bar) now wears live CPU/MEM rings. Hover to open the panel: TOKENS for usage, costs and plan limits · ACTIVITY for Mac performance · MLX for local models · plus Leaderboard, Shells and Settings. The ⤢ button pops it all out into a full dashboard window.

The model catalogue refreshes itself — new releases and live pricing appear on their own.

③ Verify

curl -s localhost:8765/health
th /stats
th /limits

Health reports the running build; th brings usage and remaining quota to your terminal. Then connect your coding agent — see MCP server.

GET FLYING

Three ways in.

① One-liner recommended

curl -fsSL https://raw.githubusercontent.com/castlemilk/token-horizon/main/install.sh | bash

Downloads the latest release, installs to /Applications, enables crash auto-recovery, wires up the th shell command. No sudo, no prompts.

② Homebrew

brew tap castlemilk/tap
brew install --cask token-horizon

Tracks releases through a versioned Cask. See packaging/homebrew for the formula.

③ Manual / from source

Grab the DMG from GitHub Releases, drag to Applications — or build it yourself:

git clone https://github.com/castlemilk/token-horizon
cd token-horizon && ./scripts/make-app.sh

Official releases are Developer ID signed and Apple-notarized; local source builds carry an ad-hoc signature.
